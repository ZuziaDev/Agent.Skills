# Global Development Rules

- Respond in Turkish unless the user explicitly requests another language.
- Use TypeScript and ESM for new Node.js code.
- Build production-ready implementations, not placeholder demos.
- Keep core logic separate from runtime adapters.
- Preserve clean public APIs and intentional exports.
- Keep future native, Python, and Rust bindings in mind at API boundaries.
- Validate external input and never expose secrets.
- Add or update tests for core behavior and bug fixes.
- Run available lint, typecheck, build, tests, and affected examples before claiming completion.
- Preserve existing project structure and unrelated user changes.
